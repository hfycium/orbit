# Orbit 设置界面方向初稿

共同约束：这是 Windows 桌面应用的作息初始设置；24 小时制；固定 / 每日 / 周制三种互斥模式；起床与睡觉时间都用可滚动的小时、分钟列。原有时间语义与交互规则不改。

## 方向 1：Windows Fluent

- 来源：Windows 11 Settings / WinUI `TimePicker` 控件文档。参考 Fluent 的侧栏导航、浅色中性面板与弹出的纵向时间选取器；Orbit 将其改成常驻滚轮以便连续录入多个时间。
- 主骨架：左侧设置导航，右侧分区表单。模式是顶端分段选择，时间成对并排。
- 主角：小时与分钟滚轮，当前值高亮，临近值降低对比度。
- 取舍：最接近 Windows 原生设置；层级明确，但时间本身不是页面主视觉。
- form：设置面板沿用桌面系统的熟悉结构，滚轮聚焦起床 / 睡觉两个关键值。

## 方向 2：夜间仪表

- 来源：Orbit 当前深色主题与进度环，以及 WinUI TimePicker 的滚动选择面。布局把实时日程弧线作为左侧视觉锚点，右侧集中输入。
- 主骨架：左右双栏；左侧日程圆环预览起床到睡觉的跨度，右侧是模式页签和成对滚轮卡片。
- 主角：日程弧线和大号当前时间；时间列支持滚动、键入和键盘上下微调。
- 取舍：品牌感最强、和悬浮球衔接自然；暗底持续使用可能不如浅色方向轻松。
- form：时间区间绕回一天的圆环，和 Orbit 的环形进度视觉同源。

## 方向 3：日程编辑页

- 来源：Windows 24 小时制时间语义与简洁编辑表单。结构先解释作息模式，再将时间编辑放在右侧紧凑列，并给出计算后的日长预览。
- 主骨架：左侧用三条大选项解释模式，右侧集中滚轮与结果预览，底部固定完成动作。
- 主角：作息区间的起止和“每天约有多少活动时间”反馈。
- 取舍：引导路径清晰，适合首次设置；密度稍高，周制需扩展为更多时间组。
- form：把时间区间作为一段可编辑的日程，而不是普通表单字段。

## 参考核查

- Microsoft WinUI TimePicker 在选中入口后垂直展开，并支持 24 小时制和分钟间隔：[官方文档](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/time-picker)。这是控件行为依据，不是代码复用许可。
- PySide6 的 `timepicker-control` 在 PyPI 标注 MIT，并描述 iOS 风格滚动时间控件；其版本发布于 2025-03-02。[PyPI 页面](https://pypi.org/project/timepicker-control/)。尚未逐行审查上游源码，不建议直接引入；目前只借鉴滚轮分列、可调分钟步长、键盘输入等交互模式。
- Orbit 自己的作息模型已支持任意分钟，默认 UI 不能强制 15 分钟步长，否则表达能力会变窄。可将“15 分钟步长”作为加速操作，而保留精确分钟选择。
